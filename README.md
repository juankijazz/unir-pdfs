# Unir PDFs

Programa para Windows que une varios PDFs en uno solo.

- Doble clic: ventana para añadir, ordenar y unir PDFs.
- Arrastrar PDFs sobre el .exe: se abren ya cargados.
- Línea de comandos: `unir_pdfs.exe -o salida.pdf a.pdf b.pdf`

## Obtener el .exe
- GitHub: pestaña **Actions** → "Build exe" → artefacto `unir_pdfs`.
- Local: ejecutar `build.bat` (requiere Python 3); sale en `dist\unir_pdfs.exe`.
